# STORY.md · DeepResearch 项目汇报

## ① 用户意图对齐

- **目标受众**：高校课程 / 项目答辩现场，台下是**任课老师**（关注设计合理性、工程完整度、数据真实性）与**同班同学**（关注能不能看懂、技术点在哪）。非投资路演、非产品发布，不需要煽动性。
- **核心目标**：讲完后观众相信三件事——
  1. 这不是「调一下 LangChain 就出来的 demo」，而是一个**决策逻辑被显式建模**的 Agent 系统；
  2. 系统的每个数字**都来自真实跑批**，包括不好看的数字；
  3. 它已经从 CLI 脚本走到了**可部署、可运维、有账号与配额**的服务。
- **PPT 长度**：**20 页**（约 12–15 分钟）。
- **视觉调性**：蓝白克制 / 学术可信 / 排版简约 / 证据优先 / 零装饰冗余。用户明确要求「中规中矩、风格简约」⇒ 在学术风结构层基础上**降低装饰密度、提高留白**，但内容页仍须撑满、不得空旷。
- **内容边界**：
  - **必讲**：问题动机、8 节点编排、critic 条件边与硬闸、防幻觉三件套、证据链、评测方法与对照实验结论、工程落地与质量门禁。
  - **不讲**：MCP 双向、HITL 交互闭环、ICP 备案、成本细账、代码沙箱的密钥泄漏细节等实施层细节（可口头补充）。
  - **禁碰**：不宣称「W8 提升了质量」；不把 coverage 39.8% 包装成好看的数字；不虚构任何指标。
