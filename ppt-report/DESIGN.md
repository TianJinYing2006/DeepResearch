# DESIGN.md · DeepResearch 项目汇报（学术风 · 简约变体）

## 0. 风格判定

- 场景 = 高校项目汇报（老师 + 同学），命中**学术风**分支：蓝白克制、证据驱动、数据必须真实可追溯。
- 用户显式指令 =「中规中矩、风格简约」⇒ **软降级**：保留学术风的**结构层**（母版骨架、色彩体系、组件族、密度下限），**常量值层**按简约诉求改写——降低装饰密度、减少色相数量、允许内容页留白到 30%（学术风默认禁用大留白，此处由用户指令覆盖）。
- 数据纪律：本 deck 所有数字均来自 `README.md` / `docs/project-status.md` 的真实跑批记录，**禁止杜撰**。不可判定的结论原样陈述。

## 5. 配图系统

- **全篇 L1 视觉类型统一 = 结构化 SVG 线稿**（架构图 / 流程图 / 链路图 / 抽象节点网络）。原因：本项目是软件系统，证据化配图就是它自己的真实拓扑；学术风禁止 3D / 卡通 / 营销插画，故**不使用 ImageGen**。

## 6. 组件族

- **编号**：浅蓝药丸 / 深蓝方块编号（28×28，白字 16px Bold）。
- **标题条**：深蓝左侧竖条 4px + 主标；或浅蓝底横向标题条。
- **卡体 TC-6**：白底 + `1px solid #D6DCE5` + radius 8；padding 16–20；凸显卡用 `boxShadow: 0 4px 20px rgba(14,63,140,0.10)`。
- **深蓝实色卡**：单页 ≤ 1、全篇 ≤ 3、多卡页禁用。
- **结论条**：页底 `#F0F5FC` 底 + 左侧 4px `#1E4FA8` 竖条，17–18px，**全篇 ≤ 4 条**。
- **KPI 巨数字**：72–120px Bold `#0E3F8C`，下方 16px 注解。
- **标签**：浅蓝药丸（radius = 高/2，12–14px 字）。

## 8. 最终硬闸门（任一不满足即返工）

1. 内容页未撑满：C 区累计高 < 470px，或元素集中在中央 60%。
2. C 区使用深色实底 / 高饱和实底。
3. 红 + 黄 > 5%，出现金色或禁用色。
4. 正文 < 22px、卡内标题 < 24px、主标 < 32px。
5. 卡片缺「标题 / 正文 / 锚底尾条」三段。
6. 深蓝实色卡超限（单页 > 1、全篇 > 3、多卡页出现）。
7. 渐变作卡片背景。
8. 文字溢出卡片、断词异常、对比度 < 4.5:1。
9. 页眉顶条 / 页码 / 章节样式全篇不一致。
10. 数字或结论无法追溯到 README / project-status 的真实记录。
11. 数据页只摆数字不给判断。
12. 总高度超出 720px（含 padding）。
