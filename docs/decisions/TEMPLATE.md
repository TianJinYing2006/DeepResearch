# ADR 模板

> 复制本模板创建新的设计决策记录。每个修复 bug / 优化设计都必须填写。

## 基本信息

- **编号**：NNNN
- **标题**：一句话概括
- **日期**：YYYY-MM-DD
- **状态**：已采纳 / 已废弃 / 被替代
- **涉及模块**：列出受影响的模块

## 背景

（当时为什么这么设计？所处上下文是什么？）

## 问题 / 动机

（现在为什么需要修改？遇到了什么问题？）

## 方案

（做了什么改动？具体实现是什么？）

## 理由与取舍

（为什么选这个方案？放弃了哪些备选方案？代价是什么？）

## 影响

（对哪些模块有影响？是否需要同步修改其他部分？）

## 变更记录

| 日期 | 变更说明 |
|------|---------|
| YYYY-MM-DD | 初始记录 |
