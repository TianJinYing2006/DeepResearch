# ADR-0018：开放注册内测（G7 落档前的边界修订）

## 基本信息

- **编号**：0018
- **标题**：取消邀请制、改为开放注册内测的边界、防滥用与回退
- **日期**：2026-10-27（主理人拍板）/ 2026-10-28（补落档）
- **状态**：已采纳
- **涉及模块**：注册与登录、防滥用与配额（`web/backend/main.py`）、`CONTRIBUTING.md` §2、ADR-0017 §3、需求 10 §3.1/§7.2、`docs/figures.md`、`CHANGELOG.md`
- **关联决策**：ADR-0017（边界重划；§6 要求边界变更必须新增 ADR）、ADR-0009（L3 架构）
- **关联实现**：#302（后端移除邀请码）/ #303（前端移除邀请入口）/ #304（文档同步）/ #306（防滥用第一层）

## 背景

ADR-0017（2026-10-26）把当前阶段定义为「L3-A/B 封闭内测」，注册方式为邀请制：邀请码一次性、可过期、可撤销，L3-C 前不开放公开注册。该边界在 2026-10-27 发生变化：主理人决定取消邀请制、改为邮箱开放注册，实现与文档同步先行落地（#302~#306），但未按 ADR-0017 §6 新增 ADR。

## 问题 / 动机

- **邀请制的代价**：需要人工发码与回收，样本偏向熟人网络；内测反馈与真实用户分布不一致；运营成本高。
- **开放注册的收益**：真实用户可自助注册，能验证「普通人能否用下去」，并为 5~10 人内测判据积累有代表性的样本。
- **开放注册的代价（显式登记）**：
  1. 批量注册与一次性邮箱可在真实 LLM 成本下放大支出（Quick ¥0.75 / Standard ¥1.25 单次预算，月度 ¥1,500 熔断）；
  2. G7 合规未落档：ICP 已备案（2026-10-21），但**公安联网备案、生成式 AI 相关手续、供应商商用授权均未完成**；
  3. 开放注册削弱「邀请制控制范围」的合规论证，是否构成「面向境内公众提供服务」需属地书面确认；
  4. 邮箱验证与 CAPTCHA 未上线，账号找回对填错邮箱的用户不可用。
- **流程问题**：实现先于 ADR 落档。本 ADR 补齐 ADR-0017 §6 的要求，并作为 ADR-0017 §3 修订的正式依据。

## 方案

1. **注册方式**：邮箱 + 密码 + 同意条款；删除邀请码字段、后端邀请码校验、`/api/options.invite_only`、管理 CLI 邀请命令、前端邀请弹窗与相关 E2E。
2. **防滥用（第一层已交付）**：
   - 注册总开关 `DR_REGISTRATION_ENABLED`（默认 true，可即时关闭）；
   - 全局每日注册上限 `DR_REGISTRATION_DAILY_LIMIT`（默认 100/日）；
   - 一次性邮箱域名黑名单 `DR_EMAIL_DOMAIN_BLOCKLIST`；
   - 叠加既有注册/登录限流、单用户并发 1、每日 1 次、单次与月度预算闸；
   - 命中分别返回 403 / 429 / 422 并写审计。
3. **边界（G7 落档前）**：允许邮箱开放注册，但**不公开推广、不投放、不对外收费、不宣布「完整产品」**；邮箱验证 / CAPTCHA 列为转段前必须补齐项。
4. **回退**：`DR_REGISTRATION_ENABLED=false` 立即停止新注册（不影响已注册用户登录）；如需恢复邀请制，须新增 ADR 并回退代码，不在本 ADR 授权范围内。
5. **转完整产品前置不变**：仍按 ADR-0017 §4 五条准入（需求冻结 / G7 落档 / 质量证明 / 安全闭环 / 治理修订）。

## 理由与取舍

- **为什么选开放注册而不是继续邀请制**：邀请制无法验证真实用户留存与体验，5~10 人内测判据也缺少代表性样本；主理人 2026-10-27 明确要求取消邀请制。
- **为什么不先补 G7 再开放**：G7 依赖外部周期（备案 / 授权），不可控；内测规模受配额、预算与运营开关约束，风险可在内部吸收。**代价是承担 G7 未落档的合规风险**，因此把「不推广 / 不投放 / 不收费」写成硬边界。
- **为什么不用代码强制总用户数上限**：注册开关与预算闸即可控制规模（关闭注册即停止新增），避免在内测期引入新的计数竞态；需求 10 §3.1 的「10 人」是**运营目标**，不是代码强制值（本 ADR 登记该口径）。
- **放弃的方案**：① 维持邀请制（样本偏差、运营成本）；② 立即转完整产品（G7 未落档、质量未证明，不诚实）；③ 只改文档不改代码（与已上线事实不符）。

## 影响

- **文档**：`CONTRIBUTING.md` §2.1/§2.3/§8.4 与 ADR-0017 §3 按本 ADR 修订；需求 10 §3.1/§7.2、`docs/figures.md`、`CHANGELOG.md` 同步；ADR-0017 §6 要求的新增 ADR 即本文。
- **代码 / 数据**：注册路径、错误码、审计；无迁移、无研究判定口径变更、无评测产物变更。
- **运维**：注册开关 / 上限 / 黑名单、预算闸、审计可查；关闭注册是第一回退手段。
- **合规**：G7 未落档风险显式登记；公安联网备案、生成式 AI 手续、供应商授权仍为转段前置。
