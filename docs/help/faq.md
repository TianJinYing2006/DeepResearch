# 帮助中心（FAQ）

> 邀请制内测版。未覆盖的问题，请通过页脚「反馈」告诉我们（登录后可见入口）。

## 账号与邀请

### 如何获得账号？
内测采用邀请制：需要管理员发放的一次性邀请码，注册时填写；邀请码一次性使用。

### 忘记密码怎么办？
登录页点「忘记密码？」→ 输入注册邮箱 → 收到重置链接（30 分钟内有效、仅可使用一次）。
重置成功后所有设备都会退出登录，请用新密码重新登录。

### 如何管理登录设备？
登录后账号条 →「会话与安全」：查看活跃会话，并「退出其他所有设备」（需输入当前密码）。

### 注销账号会删除什么？
删除账号、会话与知识库文档；任务与审核记录匿名保留（合规审计需要）；已消耗配额不退。

## 知识库

### 支持哪些格式？大小限制？
PDF / Word（docx）/ PPT（pptx）/ Excel（xlsx）/ Markdown / 纯文本 / HTML；
单文件默认上限 10MB（部署方可调 `DR_RAG_MAX_FILE_MB`）。

### 上传后一直「处理中」？
解析与向量化是异步的（通常数秒）；超过 2 分钟可点知识库「刷新」查看，或联系管理员确认处理服务状态。

### 重复上传同一个文件会怎样？
按内容去重：相同内容不会重复入库，会命中已有记录。

### 上传失败怎么排查？
上传队列会显示失败原因；常见原因：格式不支持、文件为空或损坏、超出大小/解析限额。

## 研究流程与配额

### 一次研究要多久？
取决于档位与问题复杂度；页面会显示阶段进度与预计剩余时间。

### 配额怎么算？
按「每日运行次数 / 并发 / 月度预算」三重闸；账号条可查看当日与本月用量。

### 可以取消运行中的研究吗？
可以；取消后已产生的事件与用量保留（计费以实际消耗为准）。

## 导出与分享

### 报告可以导出吗？
任务完成后可导出 Markdown / PDF（按部署配置）。

### 如何分享报告？
只读分享在路线图中；当前可导出文件后转发。

## 隐私与安全

### 我的数据流向哪里？
默认不外发用户内容出境；启用中的服务商与数据流向见《隐私政策》。
错误诊断数据默认自托管、境内存储，不采集输入内容。

### 引用可信吗？
报告引用用于溯源；检索融合分数不构成可信度承诺，请核对原文。
