# 隐私政策（草案模板）

> ⚠️ **本文件是工程草案模板，不构成法律意见。** 面向公众正式上线（L3-C）前必须经法务/合规确认、
> 补齐主体信息与联系方式，并在产品显著位置公示生效版本与日期。当前适用于内部与封闭邀请验证阶段（L3-A/B）。

## 1. 我们收集什么

| 类别 | 具体内容 | 用途 |
|------|---------|------|
| 账号信息 | 邮箱、密码哈希（Argon2id，不保存明文） | 登录与会话 |
| 研究内容 | 你提交的研究主题、附加要求、上传的文档 | 执行研究、生成报告、知识库检索 |
| 运行数据 | 任务状态、事件流、token 与成本估算、错误与降级记录 | 任务恢复、审计、成本控制 |
| 安全数据 | 登录时间、审核与申诉记录 | 安全风控与合规 |

## 2. 数据存在哪里 / 会流向谁

- 默认策略：**L3-A/B 不向境外服务发送用户内容**；境外服务（Tavily、Langfuse Cloud、arXiv、Semantic Scholar）默认关闭。
- 当前启用：阿里云百炼（模型推理 / Embedding）、博查（网络搜索）、自托管 PostgreSQL / Redis / Qdrant / 对象存储。
- 每次研究产生的检索查询词、报告草稿会发送至上述模型与搜索服务商处理；不用于其训练用途以服务商条款为准。
- 数据流向登记见 `docs/operations/production-readiness.md` §4。

## 3. 保存多久

| 数据 | 期限 |
|------|------|
| 报告与运行元数据 | 90 天 |
| 事件明细 | 30 天 |
| 审计 / 安全日志 | 180 天 |
| 上传文档（知识库） | 90 天，或你主动删除时立即删除 |

（期限来自需求 10 §3.1 推荐基线；正式上线前按合规要求复核。）

## 4. 你的权利

- **查看与导出**：随时在「历史任务」查看并导出自己的报告。
- **删除文档**：知识库上传由你自己发起，可联系管理员删除对应文档。
- **注销账号**：在账号面板执行注销（需输入密码）。注销会删除账号与会话、清理知识库向量；
  历史任务与审核记录将**匿名保留**用于审计（不再关联到你）。
- **申诉**：若内容被预检拦截或被标记，可通过 `POST /api/moderation/appeal` 提交申诉，由人工复核。

## 5. 安全

- 密码 Argon2id 哈希；会话 Cookie 为 httpOnly + SameSite；写操作有 CSRF 防护；
- 接口按用户隔离：运行记录、报告、知识库检索均按你的身份过滤；
- 密钥不入日志；错误信息不回显密码。

## 6. 未成年人

本服务面向成年人；若你不满 18 周岁，请在监护人同意下使用。

## 7. 联系方式与变更

- 联系方式：**待补充（主体信息与投诉渠道在正式上线前必须补齐）**。
- 本政策更新会在产品内公示；继续使用即视为接受更新后的版本。
